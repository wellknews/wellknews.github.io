# v1.3.1 — 규칙을 검사가 지킨다

세미콜론 쪽에서 세 가지가 어긋나 있었다. 셋 다 한 번 고치고 끝내지 않고,
«사람이 매번 확인해야 하던 것»을 «구조나 검사가 대신 지키는 것»으로 바꿨다.
그러지 않으면 다음에 또 어긋난다.

## 세미콜론이 두 개로 끝나던 다섯 편

마감 기호를 그리는 자리가 둘이었다. 세션 본문이 놓는 `Ending` 장면과, 페이지의
매듭이 새로 찍던 작은 `;`. 뒤엣것을 만들 때 앞엣것을 확인하지 않았다.

|            |                                |
| ---------- | ------------------------------ |
| 세션 5편   | `Ending` + `Closing` = **2개** |
| 나머지 9편 | 1개                            |

다섯 편만 고치지 않고 **그릴 수 있는 자리를 하나로 줄였다.** 본문은 이제 자기
끝을 선언할 방법이 없다 — 선언할 수 없으면 두 개가 될 수도 없다. 그리는 것은
원래 있던 그 장면이라 점이 내려앉는 움직임도 그대로다.

부수 효과로 마감 기호가 없던 「군단장은 본가에 있다」와 스레드·코드도 같은
기호로 끝난다. 세 게시판이 처음으로 같은 방식으로 닫힌다.

열네 편을 전부 렌더해 세었다 — 전부 한 개.

## 세 기호를 잇던 세로선

«셋이 한 자리에서 갈라져 나왔다»는 뜻으로 그었는데, 그것은 세 기호가 같은 x에
서 있는 것만으로 이미 보이는 사실이었다. 이미 보이는 것을 한 번 더 그리면 뜻이
아니라 장식이고, 그 선은 세 게시판 어느 것의 기호도 아닌 네 번째 모양이었다.

값은 이미 치르고 있었다 — 그 선 때문에 어긋남이 두 번 났다(기호에 31px 못 닿은
것, 문 사이의 실선과 십자로 만난 것). 지우고 나니 피할 대상도 없어져서 문 사이의
실선이 다른 목록과 같은 규칙을 쓰게 되었다.

## 주소의 슬래시, 그리고 두 개의 규칙

루트의 진입로에서 EKATA만 슬래시가 있었다. 어느 쪽으로 맞출지는 취향이 아니라
서버가 정한다 — 셋 다 `index.html`이 있는 실제 디렉터리라, 슬래시 없이 부르면
301을 한 번 탄다.

어긋난 것은 그 두 줄만이 아니었다. 여섯 문서 중 세미콜론 하나만 자기 canonical과
og:url을 슬래시 없이 적고 있었고(301로 튕기는 주소를 정본이라고 말하고 있었다),
사이트맵에는 EKATA 세 문서가 통째로 빠져 있었다.

두 곳의 규칙이 서로 다르다는 것도 분명히 적었다.

| 자리          | 가리키는 것      | 표기                        |
| ------------- | ---------------- | --------------------------- |
| 루트의 진입로 | 문서             | `/ekata/` `/;/` `/mamaboy/` |
| 세미콜론 안   | 앱이 만드는 자리 | `/;` `/;/session`           |

규칙이 다른 것은 가리키는 것이 다르기 때문이다. 그래서 한쪽이 다른 쪽으로 새기
쉽고, 실제로 404의 돌아가는 링크에 바깥의 표기가 새어 들어간 적이 있다.

**`npm run audit`에 열 번째 항목이 생겼다** — 이 공간 안에 적힌 주소가 이 공간의
표기를 따르는지 본다. 요소가 아니라 텍스트 노드를 걷는다. 돌아가는 링크는 화살표와
주소가 한 `<a>` 안에 있어 주소가 자기 요소를 갖지 않는데, 요소만 훑던 첫 판은
바로 그 자리를 못 보고 지나갔다. 터졌던 자리를 못 보는 검사는 검사가 아니다.
없는 주소(404)도 검사 대상에 넣었다.

일부러 규칙을 어겨 세 판면 모두에서 잡히는 것을 확인했다.

## 그 밖에

- 좁은 판면의 마감 — 글 끝의 기호와 돌아가는 길을 한 줄로 묶고, 목록에 구획선을
  넣고, 푸터 높이를 132 → 88px로 줄였다.
- CODE의 두 장치(Delta·Gate)가 `subgrid`로 한 격자를 나눠 쓴다. 주석에는 «모든
  행이 같은 폭을 나눠 쓴다»고 적혀 있었지만 실제로는 행마다 자기 격자를 갖고
  있었고, 막대가 일곱 개의 세로선에서 출발했다. 이제 세 판면 모두 편차 0px.
