# v1.26.5 — 기호에는 밑줄이 아니라 색

두 가지를 고쳤다. 둘 다 「같은 방식으로 맞춘다」가 사실은 맞추지 않은 것이었던
자리다.

## 기호는 밑줄을 긋지 않는다

왼쪽 위의 `;` 아래에 오른쪽의 SESSION·CODE·THREAD와 똑같은 밑줄이 그어져
있었다. 「현재 위치를 같은 방식으로 남긴다」는 말은 그럴듯했지만, **밑줄은
낱말의 관습이다.**

낱말 아래에 그은 선은 그 낱말을 가리킨다. 기호 아래에 그은 선은 기호의
일부처럼 보인다 — `;` 밑에 붙은 짧은 획 하나가 되어 버린다.

기호에는 색이 맞다. **기호는 획이 전부라서 획의 색이 곧 상태다.**

|                     | 색          | 밑줄 |
| ------------------- | ----------- | ---- |
| 다른 자리에 있을 때 | `#111` 검정 | 없음 |
| 다가갔을 때         | 절반쯤 물듦 | 없음 |
| 홈에 있을 때        | `#2f9e8a`   | 없음 |

처음부터 색이 들어 있으면 그것은 상태가 아니라 브랜드 표시가 된다. 여기서
색은 「지금 이 자리에 있다」는 말 한 가지만 하고, 그 말이 참일 때만 나온다.

다가갔을 때 절반만 물드는 것은 지나가는 것과 도착한 것을 구별하기 위해서다.
이미 그 자리에 있으면 더 물들 것이 없다.

## 산문에 세 번째 앉음새를 만들지 않는다

87층에서 주워들은 말이 **이 공간 어디에도 없는 활자**로 앉아 있었다.

```
본문 문단   19px    자간 normal
복도 인용   25.6px  자간 -0.512px   ← 제목용 자간
복도 속말   13px                    ← 메타데이터용 크기
```

글꼴 자체는 둘뿐이고(Hahmlet / IBM Plex Mono) 그 규칙은 지켜지고 있었다.
어긋난 것은 **크기와 자간**이다. 이 공간의 산문에는 앉음새가 둘뿐이다 —
보통의 문단(`Passage`의 note)과 한두 문장짜리(loud). 인용은 그 둘 중 어느
것도 아닌 세 번째였고, 같은 글꼴인데도 다른 글꼴을 가져다 쓴 것처럼 읽혔다.

밖에서 들어온 말이라는 것은 따옴표와, 그 말이 문 앞에 혼자 서 있다는 사실이
이미 말한다. **활자는 본문 그대로 둔다.** 들은 말과 그에 대한 속말의 낙차는
크기가 아니라 색으로 만든다.

마지막 객실 앞의 액자 두 줄(「솔직히 속으로는」 / 「라고 말하고 싶은 순간도
있었다」)도 같은 문제였다. 세리프를 메타데이터 크기로 쓰고 있었다.

이제 이 기록의 산문은 전부 19px · 자간 normal이다.
