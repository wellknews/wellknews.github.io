# v1.8.2 — 알아챌 수 있을 만큼

v1.8.1까지 잉크는 실제로 가라앉고 있었다. 다만 **알아챌 수 없었다.**

「바뀌는 중인지 원래 그런지」가 구분되지 않는 변화는 조용한 것이 아니라 없는
것이다. 한 단계 더 내렸다.

|                 | 지나온 자리의 잉크                 | 종이 대비  |
| --------------- | ---------------------------------- | ---------- |
| v1.8.0 – v1.8.1 | `--color-text-secondary` · 밝기 61 | 11.4:1     |
| 지금            | `--color-text-muted` · 밝기 88     | **6.85:1** |

본문으로 읽는 데는 여전히 문제가 없는 값이다. 이 잉크는 원래 날짜와 사진 설명이
쓰는 단계이고, 종이 위 6.85:1은 본문 기준(4.5:1)을 한참 넘는다.

구간도 조금 앞당겼다(`cover 48%~76%`). 판면 위쪽에서 가라앉은 상태가 더 오래
보인다.

CSS 쪽과 스크롤 타임라인이 없는 브라우저용 길을 **같이** 고쳤다. 한쪽만 고치면
브라우저에 따라 다른 화면이 나온다. 두 곳에서 같은 값(17 → 88)이 나오는 것을
확인했다.
