# v1.26.4 — 문이 열렸다 닫힌다

「좀 그럴싸해지긴 했는데 아무 인터랙션도 애니메이션도 없는 건가?」

재 보고 답한다. **없었다.**

```
도면   anim: none
문     anim: none
문짝   anim: none
인용   said-pass   (view timeline)
속말   back-stay   (view timeline)
```

글 두 줄만 움직이고 그림은 완전히 정지해 있었다.

## 앞 판에서 내가 한 말이 정확하지 않았다

「복도가 걸음마다 왼쪽으로 흘러간다」고 적었는데, 그 차이는 **서로 다른 세 장의
정지 그림 사이**에만 있었다. 세 걸음이 한 화면에 같이 보이는 일이 없으니
움직임으로 지각될 수가 없다. 코드에는 이동이 있고 화면에는 없는 상태였다.

그리고 개발 요청서 §23을 빠뜨리고 있었다 — **「문이 화면 중앙에 오면 조금
열리고, 지나가면 다시 닫힌다.」** 문이 처음부터 끝까지 열려 있으면 그것은 지나간
것이 아니라 그냥 그림이다.

## 둘을 넣었다

**문짝이 지나가며 열리고 멀어지면 닫힌다.** 여는 것은 가로 배율로 한다 —
정면에서 본 문은 열릴수록 폭이 줄어 보이고, 줄어든 만큼 뒤의 어둠이 드러난다.
실제로 눈에 들어오는 변화가 그것뿐이라 그것만 그린다. 손잡이도 같이 줄어드는데
그것도 맞다. 안쪽을 보여 주려는 것이 아니므로 절반쯤(0.58)에서 멈춘다.

| 판면을 지나는 동안 | 문짝        | 복도 |
| ------------------ | ----------- | ---- |
| 아직 멀리          | 1.00 (닫힘) | +53  |
| 다가오는 중        | 0.59        | +27  |
| 그 방 앞           | 0.58 (열림) | +1   |
| 지나간 뒤          | 0.97 (닫힘) | −28  |

**복도는 흘러가고 지금 지나는 방은 제자리에 선다.** 걷는 사람은 제자리이고
복도가 지나간다 — 그리고 그 방이 제자리에 있어야 아래의 글과 같은 세로선에
남는다.

## 타임라인은 바깥 상자가 잰다

SVG의 도형은 CSS의 상자를 만들지 않아서 `view()`가 잴 것이 없다. 재는 일은
복도 한 칸을 감싼 바깥 상자가 하고(`view-timeline-name: --walk`), 안쪽의 문짝과
문들은 그 이름을 가져다 쓴다.

## 움직임을 끄면

문은 **열린 채로** 서 있고, 복도는 흐르지 않고, 인용은 처음부터 또렷하다.
움직임이 없는 화면에서도 「지금 지나는 방이 열려 있다」는 사실은 남아야 한다.
