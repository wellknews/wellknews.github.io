# v1.1.0 — 세 번째 자리

SEMICOLON에 **CODE**가 생겼다. 이 레포의 첫 버전 표시다.

## CODE 게시판 신설

SESSION(경계를 가진 경험)과 THREAD(끝나지 않은 채로 이어지는 생각) 옆에
CODE(만들던 것이 어디에서 어디로 갔는지)가 앉는다.

- **세 번째 기호** `|—|—|—|—|—|` — 닫혀 있는데 안이 나뉘어 있다.
  `|————————|`(SESSION)과 `|—————···`(THREAD) 사이의 중간항이라 축의 가운데에 선다.
- **전용 조판 장치 여섯** — Stat(변경의 크기) · Delta(전과 후) · Gate(통과한 관문과
  관문이 없는 자리) · Miss(틀린 진단) · Prompt(사라진 물음) · Open(재지 않은 것)
- **첫 글** 「무거웠던 것은 목록에 없었다」 — rwkor `8cd8123 → 7d5e68d`,
  16커밋 `+1,456 −334`

## 홈의 진입로를 다시 만들었다

게시판마다 한 구간을 두고 최신 글을 통째로 펼치던 홈을 **문 세 개**로 바꿨다.
자리가 둘일 때는 `;` 하나가 두 절을 잇는 기호로 성립했는데, 셋이 되자 이음매가
둘이 되면서 기호가 아니라 구분선이 됐다. 세 기호를 한 세로줄에 세우고, 셋이
갈라져 나온 자리에 줄기를 하나 긋는다. 히어로 아래에 있던 `;`도 지웠다 —
한 화면에 같은 기호를 두 번 쓰지 않는다.

## 세 게시판의 마감을 통일했다

글 끝에 「끝」을 말하는 것이 셋 쌓여 있었다 — `;` · `← /;/code` · `← WELLKNEWS`.
셋이 같은 축에 같은 색으로 서고 그중 둘은 같은 화살표까지 썼다. 글에 속한 둘을
한 줄로 묶어 기호는 왼쪽, 돌아가는 길은 오른쪽에 놓는다.

세션의 stage 배치에는 마감 기호가 아예 없어서 이 공간의 기록 여섯 편이 전부
매듭 없이 끝나고 있었는데, 그것도 함께 없어졌다.

## 주석이 약속했지만 지켜지지 않던 정렬 세 곳

셋 다 오류가 나지 않고 「써 있는 대로 되지 않을」 뿐이라 그대로 배포되어 있었다.

| 자리              | 어긋남  | 원인                                                   |
| ----------------- | ------- | ------------------------------------------------------ |
| 홈의 줄기         | 31px    | 줄기를 문의 절반에 매어 두었는데 기호는 첫 줄에 붙는다 |
| CODE — Delta 막대 | 57–63px | 형제 격자는 칸을 공유하지 않는다                       |
| CODE — Gate 선    | 39px    | 같은 원인                                              |

줄기는 문이 아니라 기호 자신에게서 뻗게 하고, 두 장치는 칸 정의를 장치 하나로
올려 `subgrid`로 물려받게 했다. 같은 문제를 열두 페이지 × 두 판면에서 훑어
실제로 어긋난 곳은 이 둘뿐이었다. 이제 세 판면 모두 편차 **0px**.
