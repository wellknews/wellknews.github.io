「처음부터 민트색으로 보이는데.」

맞다. 앞 판에서 색을 **「홈에 있는가」**에 걸었는데, 홈이 첫 화면이라 누르기도

```
/;/          #2f9e8a   ← 들어오자마자
/;/session   #111

```

## 「있는가」가 아니라 「눌렀는가」

둘은 거의 같은 말이지만 한 자리에서 갈린다. 홈으로 바로 들어온 사람에게는
「있는가」가 처음부터 참이어서, 색이 상태가 아니라 **처음부터 칠해진 표시**가
된다. 그러면 누를 이유도 사라진다.

**눌러서 물드는 것과 물든 채로 놓여 있는 것은 다르다.**

|                    | 기호        |
| ------------------ | ----------- |
| 홈에 바로 들어옴   | `#111` 검정 |
| 기호를 누름        | `#2f9e8a`   |
| SESSION으로 감     | `#111`      |
| 기호를 눌러 홈으로 | `#2f9e8a`   |
| 홈에서 새로고침    | `#111`      |

홈을 떠나면 꺼진다. 색이 가리키던 자리를 벗어났기 때문이다. 새로고침에도
꺼진다 — 다시 들어온 것은 다시 처음이다.

`aria-current`는 그대로 둔다. 낭독에는 「지금 이 페이지」가 여전히 사실이고,
그 사실과 색은 서로 다른 것을 말한다.
