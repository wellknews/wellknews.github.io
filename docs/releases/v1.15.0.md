# v1.15.0 — 앱만 아는 사람이 읽을 수 있게

CODE 네 편을 다시 쓰고, 그림을 그리는 장치 둘을 더한다.

## 왜 또 고쳤나

직전 v1.14.0에서 「무엇이 달라졌는가」를 글의 앞으로 옮겼다. 그래도 읽히지
않았다. 읽는 쪽에서 나온 말이 이랬다.

> 처음 보는 사람이 앱만 알고 있고 내부 로직을 모른다고 가정해서 설명해야 하는데,
> 이건 이미 앱 로직을 다 알고 있다는 가정하에 풀어 쓴 느낌이다.
>
> 그리고 너무 텍스트만 있는 게 문제인 것 같기도 하다.

둘 다 맞았다. 순서만 바꾸고 **낱말은 그대로 두었던** 것이 첫째다. 「굽기가 화면
밖으로 나갔다」, 「따로 도는 일감」, 「원장에 남긴다」, 「소스풀 후보 카탈로그」 —
전부 저장소 안에서 쓰는 이름이고, 앱만 써 본 사람에게는 한 줄도 그려지지 않는다.
무엇이 달라졌는지를 앞에 놓아도 그 문장이 내부 이름으로 되어 있으면 소용이 없다.

## 낱말을 앱이 쓰는 말로 바꿨다

규칙을 `_template.tsx`에 「누구에게 쓰는가」로 못 박았다. 화면에 실제로 적혀 있는
낱말이 있으면 그것을 쓰고, 없으면 그 일이 일어나는 자리의 말로 바꾸고, 바꿀 수
없으면 처음 나올 때 한 마디로 풀어 준다. 풀 수 없으면 빼는 쪽이 낫다.

| 전                                              | 후                                                    |
| ----------------------------------------------- | ----------------------------------------------------- |
| 굽기가 화면 밖으로 나가고 따로 도는 일감이 됐다 | 카드를 만드는 동안 앱에서 딴 일을 할 수 있게 됐다     |
| 떠 있는 알약                                    | 앱 밖 렌더 알약 (설정에 적힌 그대로)                  |
| 발행처를 카드에 심고 원장에 남긴다              | 어느 언론사 기사에서 왔는지를 카드에 같이 심는다      |
| 공식 Graph API로 지표를 읽는다                  | 인스타그램이 공식으로 열어 준 통로로 숫자를 읽어 온다 |
| 소스풀 후보 카탈로그 6→8곳                      | 앱이 직접 뒤지는 매체 6→8곳                           |
| R8이 이름을 지웠다                              | 코드를 압축하는 기능이 이름을 지웠다                  |
| 카드 편집기 30초 방치 2,965프레임               | 카드 만드는 화면을 30초 방치 2,965장                  |
| 실기기                                          | 실제 폰                                               |

## 그림을 그리는 장치 둘을 더했다

장치가 여섯 개 있었지만 전부 **글자를 상자에 넣은 것**이었다. 잰 값과 빗나간
겨냥은 보여 줄 수 있어도 「그래서 화면이 어떻게 달라졌는데」에는 답하지 못한다.

**`Screens`** — 화면이 어떻게 생겼는지를 배치만 남겨 그린다. 스크린샷이 아니다.
기기에서 찍은 그림을 올리면 그날의 기사 제목과 상태표시줄까지 따라와서 무엇이
바뀐 자리인지 찾아야 한다. 사라진 자리는 자리를 남기고 점선으로 비워 둔다 —
없어졌다는 것도 배치의 일부다. `says`에는 앱에 실제로 적혀 있는 낱말만 넣는다.

**`Flow`** — 무엇이 어디를 거쳐 오는가. 이 게시판의 다른 장치는 전부 잰 값을
그리는데 이것만 순서를 그린다. 기사가 화면에 서기까지 네 자리를 거친다는 사실은
한 줄로 그리면 끝나는데 문장으로 쓰면 네 문단이 되고, 그 네 문단은 순서를 담지
못한다. 바뀐 자리는 한 칸만 표시한다.

화살표 글리프를 쓰지 않는다. 글자 크기를 따라다녀 판면이 바뀌면 선과 어긋나고,
읽는 기계에게는 「오른쪽 화살표」라고 소리 내어 읽힌다. 필요한 것은 낱말이 아니라
이어져 있다는 사실이라 선으로 긋는다.

## 만들면서 밟은 것

`Flow`의 「바뀐 자리」에 고정폭 글꼴 자간(0.14em)을 그대로 줬더니 한글이
「바 뀐 자 리」로 흩어졌다. 브라우저로 열어 확대해 보고 잡았다. 마침 `Delta`가
단위 낱말에서 같은 함정을 먼저 밟고 주석으로 적어 두었는데, 만들 때 그것을 읽지
않았다. 차례 숫자에만 고정폭을 주도록 고쳤다.

## 무엇을 안 바꿨나

숫자는 이번에도 하나도 고치지 않았다. 각 편의 revision과 diff, 본문의 측정값은
앞선 판본이 명령까지 붙여 검증해 둔 것이다. 바꾼 것은 그 숫자를 부르는 이름뿐이다
— 「프레임」을 「장」으로 적어도 2,965는 2,965다.

slug도 그대로다. 이미 나간 주소를 깨지 않는다.
