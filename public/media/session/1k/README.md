# SESSION `wellknews-1k`의 사진

이 폴더에는 아직 파일이 없다. `content/sessions/wellknews-1k.tsx`가 아래 네 장을
기다리고 있으므로, 실제 파일을 그대로 이 이름으로 넣으면 된다.

| 파일               | 무엇                         | 크기      |
| ------------------ | ---------------------------- | --------- |
| `mockup-front.png` | 앞면 시안 (토끼 심볼)        | 800×800   |
| `mockup-back.png`  | 뒷면 시안 (WELLKNEWS 레터링) | 800×800   |
| `package.jpg`      | 비닐 포장 상태의 실물        | 2000×1500 |
| `worn.jpg`         | 착용 사진                    | 1128×1440 |

크기가 다르면 `wellknews-1k.tsx`의 `width`·`height`도 같이 고친다. 그 값은
사진이 늦게 도착해도 글이 밀리지 않게 하는 자리 예약이라, 실제 비율과 달라지면
레이아웃이 한 번 흔들린다.

시안 두 장에는 `onPaper: true`가 붙어 있다. 흰 바탕에 오려 놓은 컷이라는 뜻이고,
종이 위에 곱하기로 얹어 흰 사각형이 생기지 않게 한다. 배경이 흰색이 아닌 파일로
바꾸면 그 표시를 떼야 한다.

여기에 생성 이미지를 채워 넣지 않는다. SESSION의 이미지는 장식이 아니라 증거다.
